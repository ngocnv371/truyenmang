# truyenmang.vn

A straightforward implementation similar to Royal Road. The goal is a platform for publishing, reading, and sharing online novels.

## Product Plan

### Books

- Book landing pages with title, cover, synopsis, author, genre, and status.
- Browse and discovery flows for readers.
- Metadata that supports sorting, filtering, and future recommendations.

### Chapters

- Chapter reading pages with clear navigation between chapters.
- A stable reading experience optimized for long-form content.
- Chapter lists tied back to each book.

### Comments

- Reader comments on both books and chapters.
- A lightweight discussion layer for engagement and feedback.
- Moderation hooks for future community management.

### Shared Features

- Core functionality available across books and chapters.
- Consistent UI, search, and content presentation patterns.
- Room to expand into favorites, bookmarks, ratings, and localization later.
